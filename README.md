# 🎓 Student Management System - Java

A complete CRUD-based Student Management System built in Java as part of my BCA learning journey at Asansol Engineering College.

### ✨ Features
- Add New Student (ID, Name, Course, Marks)
- View All Students
- Search Student by ID
- Delete Student Record
- Data stored using ArrayList

### 🛠️ Concepts Used
- Object Oriented Programming (OOPS)
- Classes & Objects
- ArrayList & Collections
- Loops & Conditionals

### 🚀 How to Run
```bash
javac Student.java StudentManagement.java
java StudentManagement
